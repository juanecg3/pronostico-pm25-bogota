# Notebooks del proyecto

Abre los cuadernos en orden. El primero explora la calidad y el comportamiento de los datos; el segundo revisa las variables y los retardos; el tercero visualiza la línea base de persistencia.

1. `01_eda_calidad_aire.ipynb`
2. `02_correlacion_y_retardos.ipynb`
3. `03_evaluacion_linea_base.ipynb`

Selecciona el entorno `.venv` del proyecto como kernel. Las dependencias están en `requirements.txt`.
